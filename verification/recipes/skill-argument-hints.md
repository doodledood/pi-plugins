# Skill argument hints

Shows a skill's `argument-hint` as a phantom hint after its slash command in the editor.

## How a user reaches it

- Typing a skill's slash command.
- `/skill-hints`.

## Scenarios

### tests
Run: `npm run test --workspace @doodledood/pi-skill-argument-hints`
Proves: the package's own tests pass.

### types
Run: `npm run typecheck --workspace @doodledood/pi-skill-argument-hints`
Proves: the package compiles with no type error.
