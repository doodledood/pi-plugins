# Message stash

A single-slot stash for the input editor: park a draft and bring it back later.

## How a user reaches it

- `ctrl+alt+s` and `alt+shift+s` in the editor.

## Scenarios

### tests
Run: `npm run test --workspace @doodledood/pi-message-stash`
Proves: the package's own tests pass.

### types
Run: `npm run typecheck --workspace @doodledood/pi-message-stash`
Proves: the package compiles with no type error.
