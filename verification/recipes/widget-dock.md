# Widget dock

Folds the todo and subagent widgets above the editor into one summary line.

## How a user reaches it

- Always on while those widgets have content.
- `alt+w` to expand them in full.

## Scenarios

### tests
Run: `npm run test --workspace @doodledood/pi-widget-dock`
Proves: the package's own tests pass.

### types
Run: `npm run typecheck --workspace @doodledood/pi-widget-dock`
Proves: the package compiles with no type error.
